Coding Class Table Reference

This table summarizes key JavaScript concepts, shows a small example, and includes a short text example explaining how each one works.

Concept When / Why You Use It Example & Text
if / else Make decisions in your code based on a condition. 
const age = 20;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Text example:
The line const age = 20; creates a constant variable named age with the value 20.
The line if (age >= 18) { checks the condition “is age at least 18?”.
If the condition is true, the code inside the first curly braces runs and prints "Adult".
If the condition is false, the else block runs instead and prints "Minor".
Use if / else whenever your program needs to choose between two paths. }

for loop Repeat something a set number of times or loop through a list. 
for (let i = 0; i < 5; i++) {
  console.log(i);
}

Text example:
The for loop has three parts inside the parentheses.
let i = 0; sets the starting value of i to 0 and runs once at the beginning.
i < 5; is the condition; the loop runs while this is true.
i++; increases i by 1 after each loop.
Inside the braces, console.log(i); prints the current value of i.
This loop prints 0, 1, 2, 3, and 4, then stops when i becomes 5.

Strings Work with text: trim spaces, change case, split or join. 
let name = "  Name  ";
name = name.trim();
const upper = name.toUpperCase();

Text example:
A string is text like " Name " with spaces before and after.
The line name = name.trim(); removes spaces at the start and end, so it becomes "Name".
The line const upper = name.toUpperCase(); creates a new string where all letters are uppercase, "NAME".
Use string methods like trim() and toUpperCase() to clean and transform text.

Functions Reuse logic. Name a block of code and call it later. 
function greet(name) {
  console.log("Hi " + name);
}

greet("Name");

Text example:
The line function greet(name) { ... } defines a function named greet that takes one parameter called name.
Inside the function, console.log("Hi " + name); prints a greeting using that name.
The line greet("Name"); calls the function and passes the string "Name" as the argument.
Functions let you write code once and use it many times by calling the function with different values.

Classes & Objects Model “things” with properties and methods. 
class Player {
  constructor(name, level) {
    this.name = name;
    this.level = level;
  }
}

const p = new Player("Name", 5);

Text example:
The line class Player { ... } defines a blueprint for a Player.
The constructor(name, level) runs when you create a new player and sets up this.name and this.level.
The line this.name = name; stores the name value on the new object, and this.level = level; stores the level.
The line const p = new Player("Name", 5); creates a new player object with name "Name" and level 5.
Classes and objects help you group related data and behavior together in your code.
